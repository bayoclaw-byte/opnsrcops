🎫 One-Stop EUD Onboarding

Enter a callsign and generate everything a device needs to join the COP: a TAK enrollment package (client cert + truststore + server config, one import), the Meshtastic channel QR, and the Haven gate WiFi QR. Print the kit card and drop it in the pouch.

Kit card —

1 · TAK enrollment

Scan (or open) to download the data package, then import it in ATAK / iTAK / WinTAK. One import = certs + server, done.

2 · Meshtastic channel

In the Meshtastic app: scan to join the mesh channel. Pair the pouch radio over Bluetooth first.

3 · Haven gate WiFi

Scan with the phone camera to join the gate's AP — this is the full-TAK path over the HaLow mesh.

Android (ATAK)

  1. Scan QR 3 → join gate WiFi (or use LAN).
  2. Scan QR 1 → download zip → ATAK ≡ → Import → Local SD → select zip.
  3. Server goes green; callsign is pre-set.
  4. Install the Meshtastic ATAK plugin; pair the pouch radio (BT), scan QR 2 in the Meshtastic app.
  5. Leave the plugin's “Relay to/from Server” OFF — the server-side bridge already relays; enabling it duplicates traffic.

iPhone (iTAK)

  1. Scan QR 3 → join gate WiFi.
  2. Open QR 1's link in Safari → share the zip to iTAK → Import.
  3. Off-grid fallback: Meshtastic iOS app → scan QR 2 → enable its local TAK server → point iTAK at it (app must stay foregrounded).

PC (WinTAK) / Mac

  1. Open QR 1's URL in a browser, download the zip.
  2. WinTAK: Import → Data Package → select zip.
  3. Mac: use iTAK-style config or connect via browser to Marti (admin only).
